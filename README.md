A real Black Friday deal finder: 60 deals at 4 stores (Amazon, Best Buy,
Walmart, Target), each price read on 27 Nov 2026 from a deals source that
names the store — with an honest signal on every deal (NEW LOW, STRONG, or
ROUTINE) and the same product compared across stores wherever two stores
carry it. Search, filter by category / store / discount, and sort by biggest
discount, biggest dollars saved, lowest price, or new lowest first.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network request, plain
static files under `app/` (vanilla JS + CSS).
